# Help Desk Troubleshooting Guides

Step-by-step guides for common Tier 1 support issues, written the way a help desk knowledge base article would be: symptoms, quick checks, the fix, when to escalate, and what to write in the ticket.

## Guides

| Guide | Issue |
|---|---|
| [Password reset in Active Directory](password-reset-ad.md) | User forgot their password |
| [Account lockout](account-lockout.md) | User keeps getting locked out |
| [No internet connection](no-internet.md) | Can't reach websites or the network |
| [Map a network drive](map-network-drive.md) | Shared drive is missing or won't connect |
| [Printer not connecting](printer-not-connecting.md) | Can't print or printer shows offline |
| [GPU instability on a custom PC](gpu-instability.md) | Crashes, black screens, or artifacts under load (from my own PC build) |

## How each guide is laid out

1. **Symptoms:** what the user reports
2. **Quick checks:** things to rule out in the first two minutes
3. **Fix:** the steps, in order
4. **Escalate when:** the point where Tier 1 should hand it off
5. **Ticket notes:** a template for documenting the work

## Ground rules used in every guide

- **Verify identity first** before resetting a password, unlocking an account, or changing access.
- **Start simple.** Check cables, restarts, and typos before anything complex.
- **Change one thing at a time** so you know what fixed it.
- **Document as you go.** Another technician should be able to pick up the ticket and know exactly what was tried.
